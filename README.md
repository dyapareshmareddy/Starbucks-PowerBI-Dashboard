# Starbucks Power BI Dashboard

## Project Overview

This project is an interactive Starbucks sales dashboard created using Microsoft Power BI.

The dashboard analyzes sales performance and provides insights through interactive charts, KPIs, filters, and visualizations.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Key Features

- Total Sales Analysis
- Total Orders
- Revenue Analysis
- Sales by Product Category
- Sales by Store/Location
- Monthly Sales Trends
- Interactive Slicers and Filters
- KPI Cards
- Data Visualization

## Dashboard

The Power BI dashboard provides an interactive view of Starbucks sales data and helps identify important sales trends and performance patterns.
